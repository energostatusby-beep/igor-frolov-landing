## Кейсы

### 1. Клиника доктора Аникиной — AI-бот-администратор
Клиент: Клиника доктора Аникиной, Видное, Московская область.
Продукт: AI-бот-администратор «Ольга».
Что работает:
- Telegram + Email, MAX заложен под KYC;
- ответы на входящие обращения 24/7;
- conversational orchestrator на Claude;
- лид за 3–4 хода без формы-опросника;
- crisis detector: суицид/неотложка/инсульт/агрессия → мягкий ответ + 103/112 + эскалация админу;
- multi-patient detector;
- долгая память пациента;
- voice transcription через whisper.cpp;
- фото/документы идут админу;
- approval-mode: черновики админу с кнопками;
- лиды в личку владельца, группу и Google Sheets;
- deep-link атрибуция источника;
- follow-up nudge;
- база знаний из PDF-прайса, сайта и реальных переписок.
Стек: Node.js, Claude Sonnet CLI, SQLite, whisper.cpp, PM2.
Метрики из Obsidian: 4240 строк JS, 2567 строк KB, 47 коммитов, 14 модулей, 4 ADR.
Важно: бот — администратор, не врач; не ставит диагнозы.

### 2. ForexDropBot / Pavel Drop — YouTube → Reels
Продукт: Telegram-бот для нарезки YouTube-видео в рилсы в брендинге Forex Drop.
Архитектура: Telegram → bot.mjs → pipeline.sh → 14 mp4 → Telegram.
Pipeline: yt-dlp → whisper-cli → Claude CLI → Pillow → ffmpeg.
Что показывает:
- автоматизация медиапроизводства;
- поиск моментов через LLM;
- генерация обложек;
- рендер вертикальных роликов;
- локальный запуск на Mac;
- автозапуск через launchd.

### 3. Раздели Чек / bot-split
Telegram-бот для деления совместных расходов в группе.
Что умеет:
- кнопочный UX;
- добавить трату;
- баланс;
- закрыть долги через debt simplification;
- история расходов;
- Telegram Stars donate;
- свободный текст: «Я заплатил 200 за такси...» → LLM парсит;
- фото чека → Claude распознаёт сумму, мерчанта, позиции;
- голосовое → Whisper → LLM → подтверждение.
Стек: aiogram 3.14, Python 3.13, SQLite/SQLAlchemy/Alembic, Claude CLI, local Whisper, FastAPI Mini App + Cloudflare Tunnel.

### 4. АТМ-Транс — бот записи для автосервиса
Telegram-бот записи для автосервиса в Могилёве.
Что делает:
- QR → бот → запись;
- выбор даты/времени;
- марка авто;
- услуга;
- контакт;
- подтверждение;
- уведомления админам;
- SQLite как источник истины;
- зеркало в Google Sheets;
- админ-команды в том же боте.
Стек: Python, aiogram, SQLite, gspread.

### 5. ПромЭнергоСистемы / ЭнергоШтаб — AI для операционного бизнеса
Игорь со-основатель белорусской электромонтажной компании.
Внутренние AI-задачи:
- OpenClaw: система из 7 агентов;
- маркетинг, продажи, документы, проспектинг;
- расчёты КП и обоснования цены;
- кейс Белвторресурсы: парк 42 ПЗП, оценка фикс 2800 BYN/мес, годовой потенциал 44–70 тыс. BYN.
